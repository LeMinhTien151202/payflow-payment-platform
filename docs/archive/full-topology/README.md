# Tài liệu topology cũ

Các file trong thư mục này mô tả nhánh `main` trước khi rút gọn, gồm Merchant Service,
Reporting Service và Account/Ledger tách deployable. Chúng được giữ để tham khảo lịch sử thiết kế,
nhưng đường dẫn source và lệnh Docker trong đó không áp dụng cho nhánh `portfolio-core`.

Đọc [PayFlow Core guide](../../architecture/payflow-core-guide.md) để hiểu code đang chạy.
